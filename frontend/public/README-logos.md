# Cosine Logo Assets

This directory contains the complete logo package for Cosine AI Trading Intelligence platform.

## Logo Concept

The Cosine logo is a sophisticated play on words that captures three key elements:

1. **Mathematical Foundation**: The cosine function represents the mathematical precision behind our trading algorithms
2. **Market Visualization**: The wave form mirrors the ups and downs of stock market charts  
3. **Financial Trust**: "Cosine" sounds like "cosign" - suggesting financial endorsement and trustworthiness

## Available Assets

### Primary Logos
- `logo.svg` - Main horizontal logo for light backgrounds
- `logo-dark.svg` - Version optimized for dark backgrounds with glow effects
- `icon.svg` - Square icon version for general use

### Favicon & App Icons
- `favicon.svg` - Browser favicon (simplified version)

## Usage Guidelines

### Logo Selection
- **Light backgrounds**: Use `logo.svg`
- **Dark backgrounds**: Use `logo-dark.svg` 
- **App icons/favicons**: Use `favicon.svg` or `icon.svg`
- **Social media**: Use `icon.svg` for profile pictures

### Technical Specs
- **Format**: SVG (scalable vector graphics)
- **Colors**: Blue gradient (#2563eb → #06b6d4)
- **Typography**: System fonts for maximum compatibility
- **Effects**: Built-in gradients, shadows, and glow effects

### Code Examples

```tsx
// React/Next.js usage
<img src="/logo.svg" alt="Cosine" height={40} />

// Dark mode
<img src="/logo-dark.svg" alt="Cosine" height={40} />

// Icon only
<img src="/icon.svg" alt="Cosine" width={32} height={32} />
```

### Design Elements

**Wave Pattern**: Represents both cosine mathematical function and stock market fluctuations
**Data Points**: Small circles on the wave emphasize data-driven insights
**Gradient**: Modern blue gradient suggesting technology and trust
**Typography**: Clean, professional sans-serif
