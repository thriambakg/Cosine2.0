# Cosine Logo Assets - Wall Street Chic Edition

This directory contains the complete logo package for Cosine AI Trading Intelligence platform, redesigned with a sophisticated Wall Street aesthetic.

## Logo Concept

The Cosine logo embodies the intersection of mathematical precision and financial sophistication:

1. **Mathematical Foundation**: The cosine function represents the mathematical precision behind our trading algorithms
2. **Market Visualization**: The wave form mirrors the ups and downs of stock market charts  
3. **Financial Trust**: "Cosine" sounds like "cosign" - suggesting financial endorsement and trustworthiness
4. **Wall Street Aesthetic**: Sharp edges, sophisticated gradients, and professional typography

## Design Philosophy

### Wall Street Chic Elements:
- **Clean Design**: Simplified, professional appearance without busy elements
- **Strategic Color Palette**: Red, blue, green, and dark grey representing market dynamics
- **Professional Typography**: Segoe UI with uppercase styling and letter spacing
- **Subtle Effects**: Minimal glow effects for premium feel
- **Dark Theme Focus**: Optimized for dark backgrounds with light text

## Available Assets

### Primary Logos
- `logo.svg` - Main horizontal logo for light backgrounds
- `logo-dark.svg` - Version optimized for dark backgrounds with enhanced glow effects
- `icon.svg` - Square icon version for general use

### Favicon & App Icons
- `favicon.svg` - Browser favicon (simplified version)
- `email-logo.png` - Email signature logo

## Color Palette

### Wall Street Chic Colors:
- **Red (#ff4757)**: Market volatility, risk management
- **Blue (#3742fa)**: Trust, stability, technology
- **Green (#2ed573)**: Growth, profit, success
- **Dark Backgrounds**: #0f172a to #1e293b gradients
- **Text**: White to light gray gradients

## Usage Guidelines

### Logo Selection
- **Light backgrounds**: Use `logo.svg`
- **Dark backgrounds**: Use `logo-dark.svg` 
- **App icons/favicons**: Use `favicon.svg` or `icon.svg`
- **Social media**: Use `icon.svg` for profile pictures
- **Email signatures**: Use `email-logo.png`

### Technical Specs
- **Format**: SVG (scalable vector graphics) + PNG for email
- **Colors**: Clean Wall Street palette (#ff4757, #3742fa, #2ed573, #0f172a)
- **Typography**: Segoe UI, uppercase, letter-spaced
- **Effects**: Subtle gradients and minimal glow effects
